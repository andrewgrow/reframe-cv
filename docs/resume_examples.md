# Resume content examples

Optional examples to copy and edit in the resume editor. These are not inserted automatically.

## Consent statement

```text
I consent to the processing of my personal data contained in this resume for the purpose of recruitment for the position for which I am applying.
```

Adapt the wording to the employer's application instructions. Use **Include in resume**
to control whether the statement appears in the rendered document; hiding it preserves
its saved text.
