# Tinos print fonts

Unmodified static TrueType faces, version 1.340, bundled for desktop resume PDFs.
Source: https://github.com/google/fonts/tree/main/ofl/tinos
Copyright and license: [OFL.txt](OFL.txt), from https://github.com/googlefonts/tinos/blob/main/OFL.txt

Compose uses explicit Regular, Bold, Italic, and BoldItalic faces. Keep measurement and
rendering on these same files; do not substitute an installed system font.
The font license is also packaged in the desktop application's `licenses/pdf/` resources.
